☁ Supabase Connection Setup

Paste your Supabase project URL and anon key below. These are saved to this browser only — you'll need to enter them once on each machine. See the setup guide below if you haven't created the table yet.

One-time Supabase table setup (click to expand)
Step 1 — Go to supabase.com and create a free account + new project.
Step 2 — In your project, open SQL Editor and run:
CREATE TABLE dashboard (
  id   text PRIMARY KEY,
  payload jsonb
);
Step 3 — Go to Settings → API and copy your
  • Project URL (top of the page)
  • anon / public key (under Project API keys)
Step 4 — Paste them above and click Save.
Step 5 — Repeat on the display machine — same URL and key.
That's it. Free tier handles this workload easily.
