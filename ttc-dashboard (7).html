☁ Cloud Setup

Paste your Google Apps Script URL below. This connects the dashboard to your Google Sheet so data syncs between machines automatically.

How to get your Script URL (one time setup)
1. Go to sheets.google.com and create a new blank spreadsheet. Name it TTC Dashboard.
2. Click Extensions → Apps Script
3. Delete any existing code and paste the script provided by Claude.
4. Click Deploy → New deployment
5. Type: Web app → Execute as: Me → Who has access: Anyone
6. Click Deploy, copy the URL and paste it above.
